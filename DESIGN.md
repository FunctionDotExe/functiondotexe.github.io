# Aurel: an illustrated expedition

The website is an art piece as well as Ruben Maxwell’s portfolio. The user explicitly prefers the original layered parallax landscape and rejected the paper-and-plum editorial replacement. Preserve the mountain-to-core world; refine the experience inside it.

The visual authority is the original alpine painting, layered trail and foreground, gradual blue-hour light and stars, stitched cave entrance, mineral strata, and warm core. These scenes remain full-viewport artwork, with native document scrolling driving only their decorative camera. Do not replace them with a static hero banner, opaque page sections, a card grid, or a conventional editorial portfolio.

Keep the original large cream serif lettering and warm/cool palette. Projects are objects encountered along the path. Reading areas use soft local darkness that fades into the surrounding painting, never full-width opaque section panels. Type and controls must remain legible over changing scenery.

Current refinements live in `app/refinements.css`, after the original scenic styles and before print styles. `JourneyWorld` and `JourneyMotion` retain ownership of the artwork. The original camera needs sufficient scroll distance at the cave threshold; do not shorten it to a single viewport or change stable mobile plate dimensions casually.

Navigation, identity, and actions remain visible during the scenic entrance. One primary navigation serves consistent section names. Mobile menu navigation releases the dialog’s scroll lock, waits for layout, then positions and focuses the destination using the root CSS offset. Project images and captions reserve normal layout space so sticky media cannot collide with technology labels.

Project copy states purpose and personal contribution concisely. Preserve actual work, galleries, roles, and credentials. Use verified evidence links, name ForgeFountain’s Hypixel SkyBlock context, and avoid unsupported headline performance claims. Descriptions and tool lists remain in the server document.

Reduced motion, keyboard focus, native dialogs, gallery error states, and deep links are part of the work. Verify the complete journey on desktop and mobile, including the cave handoff and expanded disclosures, before publishing to `https://aurel.rubenm.me/`.

The temporary editorial version in commit `35eb71a` is a rejected direction. Its design instructions must not guide future refinement. The original `docs/design/mountain-to-core-refinement.md` explains the world’s development; this file records the user’s current visual preference.
