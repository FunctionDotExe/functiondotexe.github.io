# Motion follows native scrolling

The current design removes the guided pacing system after the user reported choppy scrolling and rejected its floating control panel. Wheel, touch, momentum, and keyboard movement belong to the browser from beginning to end. There are no timed holds, mode switches, scroll runways, or scroll-triggered content replacements.

- Projects expose their complete story and genuine evidence in normal flow. Desktop media can remain beside the story using ordinary CSS sticky positioning; mobile media keeps a useful natural size. Galleries open only on activation.
- Skills render as six complete articles. Small neutral quartz illustrations are placed separately in the terrain. The color-changing WebGL carousel and its controls are removed from the page.
- The scenery tracks native scroll directly, with cached measurements and transforms/opacity written to individual layers. Neither wheel motion nor pointer movement creates a second easing loop.
- Disclosures open on click or keyboard activation. Hovering across a role or research heading never changes its height. Intentional expansion retains its short reversible transition, native fallback, fragment navigation, and print restoration.
- The bounded opening scene cancels on first input. Existing finite project, disclosure, portrait, and link invitations remain; the additional global title-reveal choreography is removed.

## Regression boundary

Native scrolling must not call preventDefault or write the document's scroll position. Explicit navigation, opening replay, and local gallery gestures are separate user actions. No mode preference from a prior deployment may change layout or scrolling.

Validation combines the nine interaction suites and static export checks with actual Chrome native wheel/touch and responsive rendering. The measured scenery style-work reduction and cave coverage results are recorded in [mobile skills](mobile-skills.md). JavaScript-error checks alone are not performance evidence, and headless tests do not guarantee perfect frame timing on every physical phone.
